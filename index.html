Twitter Analytics Dashboard

Power BI Data Analytics Project

I created this Twitter Analytics Dashboard using Power BI to analyze Twitter data and understand engagement, impressions, likes, retweets, replies, media views and different types of user interactions.

About the Project

In this project, I worked with a Twitter dataset and created an interactive dashboard using Power BI. I used different charts and filters to analyze tweet performance and identify useful patterns in the data. I also completed multiple analytics tasks using different conditions and filters.

Tools & Skills Used

Power BI
Data Analysis
Data Cleaning
DAX
Data Visualization
Excel

Project Analysis

The dashboard analyzes important Twitter metrics including impressions, engagements, engagement rate, likes, retweets, replies, media views, URL clicks, hashtag clicks and user profile clicks. Different filters and conditions were used to complete the assigned analysis tasks.
